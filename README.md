## How to check your Office licence (ospp.vbs)

Office 2016, 2019, 2021 and 2024 all install into the `Office16` folder. Open **Command Prompt (Admin)** and run:

```bat
:: Go to the Office folder (64-bit Office)
cd /d "C:\Program Files\Microsoft Office\Office16"

:: For 32-bit Office on 64-bit Windows, use this instead:
:: cd /d "C:\Program Files (x86)\Microsoft Office\Office16"

:: Show licence status, edition and the last 5 characters of the key
cscript ospp.vbs /dstatus

:: Install a product key
cscript ospp.vbs /inpkey:XXXXX-XXXXX-XXXXX-XXXXX-XXXXX

:: Activate
cscript ospp.vbs /act

:: Remove a key (use the last 5 characters shown by /dstatus)
cscript ospp.vbs /unpkey:XXXXX
```

In the `/dstatus` output, `LICENSE STATUS: ---LICENSED---` means Office is activated.
`LICENSE CHANNEL` shows whether the key is **Retail** or **Volume (KMS)**.

**No command line?** Open Word, then go to **File → Account**. Under *Product Information* you'll see "Product Activated" or "Activation Required".

## Common Office activation errors

| Error                                  | What it means                                      | Fix                                                                 |
| -------------------------------------- | -------------------------------------------------- | ------------------------------------------------------------------- |
| `0xC004F074`                           | No KMS server could be contacted                   | A KMS key was used outside a company network. Use a retail key     |
| `0xC004C060`                           | The product key is no longer valid                 | Replace it with a genuine key from an authorised seller             |
| "Unlicensed Product" in the title bar  | Office is installed but not activated              | Enter a genuine key under **File → Account → Change Product Key**   |
| "Product Activation Failed"            | The installed key is invalid, blocked or expired   | Remove the old key with `/unpkey`, then install a genuine one       |
| "This key can't be used"               | The key doesn't match the installed edition        | Make sure the key and install match (e.g. Pro Plus key → Pro Plus)  |

## FAQ

**Are these Office keys free to use?**
Yes. Microsoft publishes them openly, but they only work with an organisation's KMS server. They will not activate Office on a home PC.

**Why does Office still say "Unlicensed Product" after I entered a KMS key?**
There is no KMS server on your network. Remove the key and enter a genuine retail product key.

**Can I use an Office 2021 key for Office 2024?**
No. Each key works only with its own version and edition.

**Is Office 2019 still safe to use?**
Office 2019 and 2016 stopped receiving security updates on October 14, 2025. Office 2024 or 2021 is recommended.

**What is the difference between Office 2024 and Office LTSC 2024?**
Office LTSC 2024 is the volume-licensed version for organisations and uses the KMS keys above. Office 2024 (retail) is the version for individuals and small businesses and uses a retail product key.

**Does Office 2024 work on Windows 10?**
Yes, Office 2024 installs on both Windows 10 and Windows 11. Microsoft recommends Windows 11 for the best experience.
